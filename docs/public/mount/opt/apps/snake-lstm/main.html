About

This agent is a hand-written single-layer recurrent network (hidden state feeds back each tick) — a simplified RNN, not a literal LSTM (no forget/input/output gates or cell state). It is trained by evolution: each generation, every genome in the population plays one game, the best genomes are kept and the rest are regenerated by mutating them, generation after generation.
