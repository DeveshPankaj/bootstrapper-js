A trainable model needs an unbroken chain: Input → Dense/Conv2D/Conv3D/Skip/Normalization layer(s) → Output → Loss → Optimizer. Conv2D/Conv3D need a same-shape tensor flowing in (the image tasks below provide one — a flat-vector task still "works" with Conv layers, just degenerately, since there's nothing to slide the kernel over). A Skip layer adds an earlier node's output back in — its dropdown only accepts a source whose shape matches the point it's added at.
